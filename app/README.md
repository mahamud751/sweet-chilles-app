# Sweet Chillies — Member App

Standalone React Native app. Production API: **https://sweetsapi.savasuite.co.uk**

## Setup & run

```bash
cd app
npm install
npm start
```

Other terminal:

```bash
cd app
npm run android
```

## Config

`src/config/restaurant.ts` — `RESTAURANT_SLUG` for white-label tenants.
